## Interaction description

### Home page  
The home page allows users to discover **events available in their city** through a smooth vertical scrolling experience.

From this page, users can:
- Browse different events
- Join an existing event
- Create their own event

A **filtering system** allows users to refine events by type (sports, culture, school, etc.).

---

### Event creation  
The *Create Event* page allows users to **easily create a new event** by filling in:
- Title
- Description
- Date
- Maximum number of participants
- Event type
- 3 illustrative images

This page is designed to provide a simple, fast, and intuitive experience.

---

### Profile page  
The Profile page allows users to view their **personal information**.

From this page, users can also:
- **Change their current city** to see events relevant to their location
- **Log out** of the application

This page centralizes essential user account settings.

---

### Messages page  
The Messages page gathers **all conversations related to the events the user has joined**.

It allows participants to communicate easily in order to organize and exchange information before or during events.

---

## Main features
- Discovery of local events
- Event creation and participation
- Event filtering by category
- Event-based messaging
- User profile management (city, logout)
