# <center><span style="color:#4AA3A2">Feature Prioritization Matrix – MoSCoW</span></center>

## Methodology

To do the feature prioritization, we have employed the MoSCoW method, which categorizes features into four distinct groups:
- **Must Have**: Essential features that are critical for the product's success.
- **Should Have**: Important features that add significant value but are not critical.
- **Could Have**: Nice-to-have features that enhance user experience but are not necessary.
- **Won’t Have**: Features that are not planned for the current development phase.

---

## <center><span style="color:#F27438">Must Have</span></center>

| Feature | Justification |
|-------|---------------|
| User registration & login | Required to identify users and secure access |
| Create events | Core functionality of the application |
| Join / Refuse an event | Main user action |
| Basic Filter events| Enhances user experience by personalizing content |
| View event details | Essential for users to get information about events |
| Chat in the event Group | Facilitates communication among event participants |
| See our / others profile | Important for social interaction and trust building |
| Swipe left/right on events | Intuitive way to browse through events |
| Location based event suggestions | Increases relevance of event recommendations |

---

## <center><span style="color:#A7001E">Should Have</span></center>

| Feature | Justification |
|-------|---------------|
| Parameters | Allows users to customize their experience |
| Edit profile | Important for user personalization |
| Ask to join private events | Enhances user engagement and event exclusivity |
| Feedback system | Helps other to know how a user is |
| Advanced Filter events | Further personalizes event recommendations (Interest / Age / Localisation) |

---

## <center><span style="color:#DAAB3A">Could Have</span></center>

| Feature | Justification |
|-------|---------------|
| Notifications | Useful but not critical for MVP |
| Friends list | Builds social connections within the app |
| Private messaging | Enhances user communication options |
| Event reminders | Improves user attendance rates |
| Invite friends to events | Encourages user growth and engagement |

---

## <center><span style="color:#5D7052">Won’t Have</span></center>

| Feature | Justification |
|-------|---------------|
| Video calls | Too complex for the initial version |
| Voice messages | Not essential for core functionality |
| Calendar integration | Can be added in future iterations |
| Social media sharing | Not a priority for MVP |
