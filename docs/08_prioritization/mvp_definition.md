# Mvp definition


## 1. Main user flow 

- Login/Sign-up: The user identifies themselves to access the platform.
- Consultation: Browsing the list of available events on the home page.
- Creation: The user creates a new event via a dedicated form.
- Interaction: The user joins a group chat for an event they have been accepted to.

## 2. Essential screens

- Login/Sign-up: Entry form.
- Home Page: Event feed.
- Creation Screen: Form with mandatory fields (name, type, description, age, dates).
- Messaging: List of active group chats.
- Profile: Viewing user information.

## 3. Minimal features

- Authentication system: Basic account creation and login.
- Dynamic display: Swipe left or right to accept or refuse an event.
- Basic filters: Filtering by activity type (e.g., Sports, Outings, Games).
- Creation form: Saving an event with title, category, description, required age, and dates.
- Group chat: Sending and receiving real-time text messages in event groups.
- Profile consultation: Viewing your own profile and other users' profiles.
- Event details: Viewing different information about an event.
- Events by location: Suggesting events closest to the person searching (based on city name).

## 4. What is explicitly excluded

- Real-time geolocation: The location will be entered as text (ex:"Toulouse") and not via an interactive map (ex: Google Maps).
- Complex approval system: For the MVP, joining an event will be automatic (no validation waitlist from the organizer).
- Push notifications: No mobile or browser alerts.
- Profile statistics: The "number of events attended" will be static or simulated
