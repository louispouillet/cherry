# <center> Feedback Summary </center>

This document summarizes the feedback received from users regarding the documentation and provides insights into areas of improvement.

## Feedback 1 : 

We received feedback from a user who didn't find how we could make some profit from our application. So She suggested adding ads or premium features to generate revenue. She talked also about the rating aspect and told us to make it so that after an event is over, user can rate the event and the other participants with 3 or 4 different emojis (happy, sad, angry, neutral). So this way, we could have a better idea of how the event went and how the participants behaved.
Therefore, she said the application was a god idea and that it could be really useful.

## Feedback 2 :
Another user suggested improving the user interface to make it more intuitive and user-friendly. They recommended adding a tutorial for first-time users to help them navigate through the application easily. Additionally, they proposed integrating social media sharing options so users can share their events and experiences with friends and family.
