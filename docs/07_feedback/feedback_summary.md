## Feedback 2 :
Another user suggested improving the user interface to make it more intuitive and user-friendly. They recommended adding a tutorial for first-time users to help them navigate through the application easily. Additionally, they proposed integrating social media sharing options so users can share their events and experiences with friends and family.

## Feedback 3 :

We also received feedback from Noiraud Pauline. She suggested adding a feature that allows users to create personalized event reminders and notifications, so participants don’t miss upcoming events. She also recommended including a search and filter function to easily find events based on categories, dates, or location. Furthermore, she emphasized the importance of providing clear instructions and guidance for event creation, ensuring that new users can set up events quickly and correctly. Overall, she found the application to be promising and believes that with these improvements, it could become even more user-friendly and engaging.

## Feedback 4 : 

We received feedback from Aurelie. She recommended including a map integration to help users easily locate events and see nearby activities. Additionally, she mentioned that implementing a “favorites” feature would allow users to save events or organizers they like for quicker access in the future. Overall, she appreciated the concept of the application and believes that these additions would make it more interactive and convenient for users.

## Feedback 5 :

We received feedback from Kelian. He suggested adding a feature that allows users to accept or join an event as a group, so that a friend group doesn’t have to join individually. This would make it easier for groups of friends to participate together and enhance the social experience of the application. He also mentioned that it could be useful to have a way to manage group invitations and see which friends have confirmed attendance. Overall, he thought this feature would make the app more convenient and enjoyable for group activities.
